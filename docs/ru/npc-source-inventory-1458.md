# Исходный inventory NPC 1.4.5.8

Независимый inventory dedicated server вызывает `NPC.SetDefaults` для `1..696` и `SetDefaultsFromNetId` для `-1..-65`: 761 исходный результат. `NPCID.Count = 697`; последний ID `696` использует AI style `127`. Пять идентичностей с нулевой жизнью (`76`, `146`, `403`, `404`, `408`) оставляют 691 положительное определение.

Доступный для запросов охват — **691 положительный / 65 знаковых**. Исходные defaults создания охватывают **501 положительный / 63 знаковых**; **190 положительных / 2 знаковых** остаются только классическими метаданными. [Блок AI3/AI7](npc-ai3-ai7-roster-1458.md) закрывает оба roster definitions (191+27 и 82+0). Числа относятся к definitions/defaults, а не к полному AI или сражениям. `FullVanillaAiParity` остаётся false.
