# Raw-цели летающих NPC и дети Hive, 1.4.5.8

Локальная приёмка одиннадцатого блока: 1553881/1553882 тестов, без ошибок и падений, один прежний пропуск worldgen; чистая Release-сборка, Windows NativeAOT, пять smoke-проверок и локальные gates прошли. См. [контрольную точку NPC](../roadmap/npc-ai-parity.md). Предыдущие записи о кандидатах и ожидаемой приёмке ниже описывают свои исторические блоки. Полная совместимость геймплея и NPC остаётся открытой.

Принятый одиннадцатый блок расширяет существующего владельца raw-слотов на допущенных летающих AI002 и добавляет отдельного владельца сохранённого AI005 для Bee210/SmallBee211. Общая локальная приёмка записана выше; `FullVanillaAiParity` остаётся false.

AI002 отдельно сохраняет текущий raw-слот и результат ближайшего поиска. Дневное отступление читает принадлежащий игроку `ZoneGraveyard` текущей цели до переназначения. Для конструктора/сброса и sentinel255 известен false; nullable-зона импорта отклоняет только ветвь, которая действительно её читает. Мёртвая цель сохраняет направление в исходной фазе обновления цели. Pigron FindFrame действительно может скопировать direction0 в spriteDirection0; такое значение допускает только обновление того же определения Pigron. Проверки настоящего RNG, точных снимков/жизненных циклов игроков, кандидатов и версий секций предшествуют принятию. Внешняя фаза production сохраняет действительный счётчик CheckActive и публикует update23, затем life0/inactive23 до следующего физического слота, включая пропуск следующего спавна.

Bee относится к **AI005, а не AI002**. `VanillaBeeTarget1458` реализует поиск NPC, не являющихся пчёлами, и игроков по возрастанию слотов, строгое сравнение расстояния NPC со скорректированным расстоянием игрока, направление по целочисленному прямоугольнику и сохранение цели/направления при пустом поиске. Исключены Bees, Queen Bee и Hive/Honey Slime. `GetTargetData.None` действительно содержит нулевой прямоугольник; неверная сохранённая цель255 не подставляет тело игрока-конструктора. Отдельный владелец передаёт данные проверенному примитиву AI005 ramp/jitter/bounce, сохраняет действительную NPC-цель даже после потери chaseability, завершает исходный проход платформ, поворот/направление и немедленный CheckActive, затем принимает результат через существующий точный preview таблицы слотов/RNG.

Проверка рождения Hive требует этого конкретного владельца Bee и известных фактов тела/chaseability соседних NPC и игроков. Неизвестные данные отклоняются до принятия родителя/ребёнка/RNG. При допущенных владельцах Hive теперь рождает ребёнка без живых целей: больший слот обновляется в том же проходе NPC; меньший сохраняет ожидающее поколение до своей очереди. Если родитель исчезает первым, больший слот ребёнка ищет цель в получившейся живой таблице и может двигаться к типизированному None до собственного удаления. Инициализация direction0 у Blue Slime происходит до обновления мёртвой цели, которое сохраняет уже установленное направление.

Независимые данные включают 2 496 оригинальных строк NewNPC/связанных IdleSounds+AI002/полного UpdateNPC; 5 424 настоящих строк Bee AI005/UpdateNPC, включая 24 случая None около начала координат; и 72 вызова настоящего оригинального `Main.UpdateWorld_NPCs` с `ignoreErrors=false`, содержащих 24 действительных рождения. Тесты полного прохода сравнивают состояние, очередь слотов детей, время жизни, общий RNG и настоящие байты socket23 первого прохода. Девять проверок владельцев охватывают изменение ревизии соседнего NPC без изменения значения, ABA raw-жизненного цикла, версии мира, неизвестные данные соседей и избирательный допуск неизвестной зоны кладбища. Все 8 001 новых и 116 002 восстановленных соседних проверок проходят без падений, ошибок и пропусков.

Шесть контролей копии возвращают старый запрет raw-целей, замену нулевого sprite, вымышленное тело конструктора для None, бездействующую Bee без живых целей, перезапись направления мёртвой цели и удалённые серийные проверки соседей. Они дают соответственно 2 288/96/16/4 344/24/2 падения утверждений без ошибок runner. Контроли меняют только отдельные копии; tracked source никогда не откатывается. Данные сохранены в `.cache/raw-flight-eleventh-final-focused.xml`, `.cache/raw-flight-eleventh-controls/results.json` и `.cache/raw-flight-eleventh-adjacent.xml`.

NoAggro, отрицательный Aggro/история прежней цели, выбор tank-pet, неизвестные импортированные факты игроков/соседей, выбранные производители Torch/Herb/Web и более широкие статусы/кадры/частота сетевых обновлений остаются ограниченными или открытыми. Оригинальная Linux-сборка выполнялась на Windows CoreCLR; это не Linux NativeAOT и не новое доказательство арифметики Windows Framework. См.
