# Исходный каталог definitions NPC 1.4.5.8

[English](../en/npc-source-definition-roster-1458.md) · [Граница NPC runtime](npc-behavior-runtime-boundary.md)

Доступный для запросов каталог охватывает 691 из 696 положительных исходных идентичностей и все 65 знаковых вариантов. ID `76`, `146`, `403`, `404`, `408` имеют нулевую исходную максимальную жизнь и остаются исключёнными. У `664` ненулевая жизнь и нулевое тело: метаданные доступны, разрешение геометрии отклоняется.

Исходные defaults создания теперь охватывают **501 положительную идентичность и 63 знаковых варианта**. [Блок AI3/AI7](npc-ai3-ai7-roster-1458.md) добавляет 106 положительных definitions и 27 знаковых вариантов к исходным 395 положительным / 36 знаковым defaults ветки `main`. Для полного roster AI3/AI7 он также разрешает применимые преобразования сложности и мира через существующий NPC store. Поддержка definition не допускает непроверенное автономное AI.

133 добавления имеют `CreationDefaultsOnly`; `SupportsRuntimeLifecycle` сохраняет прежние 431 явную регистрацию. Создание/defaults и пакетная проекция используют реальные исходные данные, а недоказанные пути AI/status/combat/death/role остаются закрытыми.

Оставшиеся **192 metadata-only идентичности** (190 положительных, 2 знаковых) предоставляют классические исходные defaults с `DefinitionOnly = true`, `BehaviorFamily.None` и `PhysicsFamily.None`. Точный hitbox после масштабирования сохранён без выдумывания сырых размеров. Vanilla-создание отклоняет такие строки до callbacks контекста, RNG и выделения слота. Явное ручное сохранение/удаление и специально зарегистрированное пользовательское поведение сохраняют прежнее владение.

Для metadata-only импорта пакет `23` по-прежнему требует явной текущей максимальной жизни и корректного live hitbox override. Lookup не заполняет неизвестные импортированные факты. Прежние исходные байты также подтверждают сериализацию release-owner для Gold NPC ID `442..448`; поддержка wire сама по себе не допускает игровую ловлю/выпуск.

Полный исходный inventory содержит 761 результат оригинальных `SetDefaults` / `SetDefaultsFromNetId`. Сохраняются только числовые факты. Полный census семейств, добавления, преобразования defaults и общее исправление лестниц описаны в [roster AI3/AI7](npc-ai3-ai7-roster-1458.md). `FullVanillaAiParity` остаётся false; явный допуск поведения и физики, специфические эффекты типов и более широкая совместимость runtime остаются отдельной работой.
