# Multi-world и sandbox runtime

Подробная архитектура sandbox вынесена в отдельный [каталог документации sandbox](sandbox/README.md).

Нормативная дорожная карта теперь находится в [`../roadmap/sandbox/README.md`](../roadmap/sandbox/README.md).

Эта страница остаётся стабильной точкой входа для существующих ссылок. Sandbox runtime не является заменой Dimensions; он даёт in-process и dedicated-process isolation поверх одной основы `WorldRuntime`.
