This scalar support does not admit new NPC definitions or AI.

`RuntimeWorldInvasion1458` owns the live state. A repeated or stale preparation cannot award credit. A replacement generation survives old terminal publication. Frost uses progress icon `5` and the same late-join and detached save handoff as other owned invasions.

Completion at the existing world-update boundary clears the active invasion, commits the `FrostLegion` milestone and publishes progression event `12`, the source warning and world information. First completion retains a pending Lantern Night; a repeated completion does not create another pending night. The saved `downedFrost` byte is located between Clown and Pirates in the verified current header layout.
